# Nhat-Quang Nguyen — academic website

Static academic website prepared for https://nhatquang-nguyen.github.io/.
No build step or package installation is required.

## Publish with GitHub Pages

1. Sign in to the GitHub account `nhatquang-nguyen`.
2. Create a public repository named exactly `nhatquang-nguyen.github.io`.
3. Add the contents of this folder to the root of the repository on `main`.
   `index.html` must be at the repository root, beside `styles.css`.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose **main** and **/(root)**, then click **Save**.
7. Wait for the Pages deployment to finish and visit
   https://nhatquang-nguyen.github.io/.

If this repository already exists, inspect it before updating it. Preserve
existing content that is not part of this website.

## Update the website

- `index.html`: biography, research, publications, presentations, teaching,
  media and contact information.
- `styles.css`: responsive layouts and typography.
- `images/`: portrait image.
- `citations/`: downloadable BibTeX citations.
- `research-motif.svg` and `favicon.svg`: decorative website graphics.
- `robots.txt` and `sitemap.xml`: search discovery files.

Changes committed to the publishing branch are published by GitHub Pages.
Do not add a downloadable CV until an updated version is ready.

After publication, add the website URL to your academic profiles. You can
verify the URL in Google Search Console and request indexing; appearing in
search results is not guaranteed or immediate.

Official setup instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
